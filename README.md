# The Little Atelier
The Little Atelier is a personal developer portfolio that showcases my
projects, technical skills, academic development, and creative work.

## About The Project
The portfolio was designed to present my development journey through a
combination of structured technical content and an editorial-inspired
visual identity.

It includes selected programming and web development projects, information
about my skills and education, credentials and achievements, and a contact
section.

## Features
- Responsive portfolio design
- Desktop, tablet, and mobile layouts
- Project archive
- Project details and case studies
- About and development journey
- Skills and technologies
- Education
- Credentials and achievements
- Contact section
- Light and night visual themes
- Editorial-inspired interface

## Technologies

## Design Direction
The Little Atelier follows an editorial and minimal visual direction,
combining soft paper-inspired colors, serif typography, structured layouts,
and subtle interface details.

### Typography
- **Cormorant Garamond** — Display typography and headings
- **Inter** — Body text and interface elements

### Visual Style
- Editorial
- Minimal
- Personal
- Artistic
- Structured
- Responsive

## Projects
The portfolio features selected projects developed throughout my academic
and personal development, including Java, Python, web development, and
UI/UX projects.

## Responsive Design
The portfolio was designed for multiple screen sizes:
- Desktop — 1440px
- Tablet — 768px
- Mobile — 390px

The layout, spacing, navigation, and interface elements adapt according
to the available screen size.

## Purpose
The Little Atelier serves as a personal space for documenting my growth
as a developer while bringing together my technical, academic, and
creative interests.
