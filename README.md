# The Little Atelier

A personal developer portfolio showcasing programming projects, academic work, and creative exploration through an editorial-inspired web experience.

## Overview

The Little Atelier is a responsive, multi-page developer portfolio designed to present personal projects, technical interests, academic work, and ongoing development progress.

Built with a focus on simplicity, readability, and visual consistency, the website combines a minimalist interface with an editorial-inspired design. It provides an organized browsing experience through dedicated pages for introductions, project collections, detailed case studies, and contact information.

The project also serves as a practical application of frontend development concepts, particularly semantic HTML, CSS architecture, JavaScript interactions, responsive layouts, and user experience design.

## Features

- Responsive multi-page portfolio
- Personal introduction and featured projects
- Project archive with category filtering
- Dedicated project case study page
- Light and dark theme support
- Mobile navigation
- Skills and technology sections
- Contact information and frontend contact form
- Responsive layouts for desktop, tablet, and mobile devices
- Keyboard focus styling
- Reduced-motion support

## Website Pages

### Home — `index.html`

The main landing page introduces the developer, highlights selected projects, and presents technical interests, skills, and areas of learning.

### Projects — `projects.html`

A centralized project archive featuring development work organized into categories for easier browsing and discovery.

### Project Details — `project-details.html`

A dedicated case study documenting the Academic Peer Review Platform, including its objectives, implementation, workflow, limitations, and development insights.

### Contact — `contact.html`

Provides contact information, professional links, and a frontend contact form interface.

**Note:** The contact form is currently frontend-only and does not submit messages to a backend service.

## Featured Projects

### Academic Peer Review Platform

A console-based Java application designed to simulate an academic manuscript evaluation process, covering manuscript submission, reviewer assignment, peer evaluation, and editorial processing.

**Technologies:** Java, Object-Oriented Programming, Interfaces, Inheritance, Polymorphism, Abstraction, and Exception Handling.

### Tiny School Adventure

A Java-based school-life simulation project exploring interactive activities, character relationships, quests, item management, and save/load functionality.

**Technologies:** Java, Object-Oriented Programming, and JavaFX.

### Inkwell Writers Hub

A creative writing and publishing-inspired web project designed around a digital space for writing and content presentation.

**Technologies:** HTML5 and CSS3.

### Python Inventory Manager

A console-based application focused on inventory management, data organization, and fundamental programming logic.

**Technology:** Python.

## Design Philosophy

The Little Atelier follows an editorial-inspired visual direction that balances simplicity, elegance, and functionality.

Its visual identity incorporates:

- Paper-inspired backgrounds
- Muted rose accents
- Dark ink-inspired tones
- Serif typography for headings
- Clean sans-serif typography for body content
- Generous whitespace
- Consistent spacing and page layouts

The overall design aims to create a comfortable browsing experience while maintaining a recognizable visual identity throughout the website.

## Running Locally

### Prerequisites

- A modern web browser
- Visual Studio Code or another code editor
- Git (optional, for cloning the repository)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/the-little-atelier-portfolio.git
```

**2. Navigate to the project directory**

```bash
cd the-little-atelier-portfolio
```

**3. Open the project**

Open the folder in Visual Studio Code.

**4. Run the website**

Open `index.html` directly in your browser or launch the project using the Live Server extension.
