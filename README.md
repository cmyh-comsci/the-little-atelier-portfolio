# The Little Atelier
A personal developer portfolio showcasing programming projects, academic work, and creative exploration through a soft, editorial-inspired design.

## About the Project
The Little Atelier is a responsive, multi-page developer portfolio created to present my projects, technical interests, and development journey. It combines a minimal visual identity with organized project information to create a professional and approachable browsing experience.
This project was developed as part of my web development learning journey, with an emphasis on semantic HTML, CSS organization, JavaScript interactions, responsive design, and user experience.

## Features
- Responsive multi-page portfolio
- Personal introduction and featured projects
- Project archive with category filters
- Detailed Academic Peer Review Platform case study
- Light and dark theme support
- Mobile navigation
- Skills and technology sections
- Contact information and frontend contact form
- Responsive layouts for desktop, tablet, and mobile
- Keyboard focus styling and reduced-motion support

## Pages
### Home — `index.html`
Introduces the developer, highlights selected projects, and presents technical interests and areas of learning.

### Projects — `projects.html`
Displays the project archive with categories for organizing and browsing development work.

### Project Details — `project-details.html`
Presents a detailed case study of the Academic Peer Review Platform, including its objectives, implementation, workflow, limitations, and lessons learned.

### Contact — `contact.html`
Provides contact information, professional links, and a contact form interface. The form is frontend-only and does not send messages to a backend service.

## Featured Projects

### Academic Peer Review Platform
A console-based Java application designed around manuscript submission, reviewer assignment, peer evaluation, and editorial processing.

**Technologies:** Java, object-oriented programming, interfaces, inheritance, polymorphism, abstraction, and exception handling.

### Tiny School Adventure
A Java-based school-life simulation project exploring interactive activities, relationships, quests, items, and save/load functionality.

**Technologies:** Java, object-oriented programming, and JavaFX.

### Inkwell Writers Hub
A creative writing and publishing-inspired web project.

**Technologies:** HTML and CSS.

### Python Inventory Manager
A console-based program focused on inventory management and basic data organization.

**Technology:** Python.

## Technologies Used
- **HTML5:** Page structure and semantic content
- **CSS3:** Styling, layout, themes, and responsive design
- **JavaScript:** Interactive behavior and interface enhancements
- **Git and GitHub:** Version control and source-code hosting
- **Visual Studio Code:** Development environment

## Design Approach
The visual identity uses an editorial-inspired style featuring paper-like backgrounds, muted rose accents, dark ink tones, serif headings, clean sans-serif text, and generous whitespace.
The design aims to maintain visual consistency across pages while keeping content readable and navigation intuitive.

## Running Locally
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use a local development server such as the Live Server extension.
4. Navigate through the website and test its interactive features.
